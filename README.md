# Конспект: Вкладка Source Control в Visual Studio Code
* **Source Control** (Управление исходным кодом) - встроенный в VS Code инструмент для работы с системами контроля версий (чаще всего с Git). Он позволяет отслеживать изменения в файлах, фиксировать их и отправлять в удаленный репозиторий (например, на GitHub).

---  

## 1. Интерфейс и запуск
* **Как открыть:** Иконка с веткой и кружками на левой боковой панели или сочетание клавиш `Ctrl + Shift + G` (для Windows) / `Cmd + Shift + G` (для macOS).
* **Инициализация:** Если проект еще не отслеживается, во вкладке появится кнопка **Initialize Repository.** Нажатие на нее создает скрытую папку .git в корне проекта.

---
 
## 2. Статусы файлов (Changes)
Рядом с измененными файлами отображаются буквы-индикаторы:
* **`U` (Untracked)** - Новый файл, который Git еще не отслеживает.
* **`M` (Modified)** - Ранее сохраненный файл, в который внесли изменения.
* **`A` (Added)** - Файл добавлен в индекс (Staged) и готов к фиксации.
* **`D` (Deleted)** - Файл был удален из проекта.

---
  
## 3. Основной рабочий процесс (Workflow)
1. **Просмотр изменений (Diff):** Одиночный клик по файлу в списке открывает окно сравнения ("было" слева / "стало" справа).
2. **Индексация (Staging):**
* Нажатие на плюс `+` напротив конкретного файла переносит его в категорию Staged Changes (Подготовленные изменения).
* Нажатие на `+` напротив общего заголовка Changes индексирует сразу все измененные файлы.
3. **Фиксация (Commit):**
* В поле *Message* сверху вводится краткое описание изменений.
* Нажатие кнопки Commit (или галочки) сохраняет эту версию в локальную историю проекта.
4. **Синхронизация (Push / Pull):**
* Кнопка **Sync Changes** (или стрелки в левом нижнем углу окна) отправляет ваши коммиты на удаленный сервер и скачивает чужие обновления.

---

## 4. Дополнительные возможности
* **Управление ветками:** Текущая ветка отображается в самом низу слева в статус-баре. Клик по ней открывает меню для переключения или создания новых веток.
* **Меню «Три точки» (`...`):** Содержит расширенные команды Git (отмена последнего коммита, прятание кода в `Stash`, разрешение конфликтов слияния).
